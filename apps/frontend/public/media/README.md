# Демонстрационные материалы Lumo

Все SVG-обложки и MP4-анимации созданы для этого проекта скриптом
`apps/frontend/scripts/generate-demo.py`. Сторонние видеоролики не используются.
Каждая анимация длится 8 секунд, разрешение 1280×720, H.264 без звука.
Названия, каналы и статистика в интерфейсе — демонстрационные примеры.

Для повторной генерации нужен Python 3 и FFmpeg с librsvg и libx264:

```bash
python3 apps/frontend/scripts/generate-demo.py
```
